## About

Security-focused write-ups covering exploitation techniques, payload construction, and remediation guidance for common web vulnerability classes (XSS, SQLi, access control, and more as the collection grows). Each write-up aims to explain not just the *payload*, but the *reasoning*: why the context demands that breakout, and how to fix it.
